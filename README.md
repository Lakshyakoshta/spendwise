# SpendWise

SpendWise is a personal finance management web application.

## Purpose

This project is being built as a learning project to understand
the complete software development lifecycle of a modern web application.

## Planned Technology

### Frontend
- Next.js
- TypeScript

### Backend
- Java
- Spring Boot
- Maven

### Database
- PostgreSQL
- Flyway

### Infrastructure
- Docker
- Docker Compose

### Development & Delivery
- Git
- GitHub
- CI/CD

### Observability
- Logging
- Metrics
- Monitoring
- Tracing

## Architecture

Next.js → Spring Boot → PostgreSQL
